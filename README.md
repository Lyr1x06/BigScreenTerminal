# 大屏控制终端

Windows 10/11 桌面程序，作者 Lyr1x。

## 功能

- **定时关屏**：在指定时间、指定星期，切换到独立 Windows 桌面，显示覆盖所有显示器的纯黑窗口。原桌面上的程序继续运行，它们的置顶窗口无法插到关屏桌面上。仅鼠标右键切回原桌面，左键、中键、Esc、Enter、空格和 Alt+F4 均不会退出关屏。系统不允许切换桌面时，自动改用原桌面的覆盖窗口、层级事件监听和 8 毫秒置顶检查；备用方式仍可能与持续抢置顶的程序竞争。系统安全桌面和锁屏由 Windows 管理。
- **定时关机**：在规则中选择「关机」和生效的星期。到点调用 Windows 的正常关机命令，不强制结束其他程序。程序必须保持运行（可以收起到托盘）；Windows 完全关机后，软件无法自行启动电脑。
- **关机前天气提醒**：开启后，在每条定时关机规则前约一分钟查询今明两天天气。优先使用 Windows 本机定位服务，系统定位不可用时使用输入的城市或公网 IP 定位；默认温度变化达到 5°C，或明天出现雨雪／降水时弹出明天天气。天气查询在后台进行，网络失败不会阻止定时关机。
- **任务栏自动隐藏监测**：程序运行期间每 100 毫秒检测 Windows 设置中的「自动隐藏任务栏」开关，发现开启就通过 Windows 接口关闭并同步保存值。收起到托盘后继续检测；Explorer 重启后自动重试。其他程序进入全屏时，Windows 仍按自身规则处理任务栏。
- **自绘窗口**：不透明蓝色界面，无系统默认白色标题栏，提供最小化、最大化和关闭按钮、拖动及边缘缩放。窗口没有系统毛玻璃效果。
- **托盘与开机自启动**：开启「最小化到托盘」后，关闭或最小化主窗口会继续在托盘运行。开机自启动通过当前用户注册表 Run 项实现。
- **开机启动项管理**：点击「开机启动项管理」，检测当前用户、所有用户的注册表 Run 项（含 32 位软件）以及启动文件夹。支持搜索、刷新、启用和禁用，保留原始命令与文件。更改在下次登录 Windows 时生效，不会结束正在运行的软件。所有用户的项目可能需要以管理员身份运行后修改；未知状态只显示、不修改。此列表不包含服务、计划任务、打包应用启动任务等其他启动来源。

原来的音频透传和手动显示/隐藏任务栏功能已移除。旧版重复关屏规则会迁移成每天的关屏规则；旧版单次关屏规则会迁移为停用状态，避免意外每周重复执行。

## 使用

在「定时规则」中点击「添加规则」，分别选择时间、动作和星期，使用「启用」开关控制该规则。勾选「仅执行一次」后，在下一次符合时间和星期的时刻触发，触发前保存为停用状态；重启程序后仍保持停用。需要再执行时重新启用规则。右侧「关机前天气提醒」可关闭提醒、填写城市或调整温差阈值；位置留空会优先调用本机定位。点击「立即查看天气」可随时测试查询。定时关机不会弹出确认框；主界面不再提供手动立即关机。运行期间不需要保持主窗口打开。

设置保存在 `%APPDATA%\BigScreenTerminal\settings.json`。要让时间表在每次登录后持续工作，请打开「开机自启动」。

## 开发和打包

```bat
pip install -r requirements.txt
python -m unittest discover -v
python main.py --selftest
python main.py
build.bat
```

`build.bat` 生成 `dist\BigScreenTerminal\BigScreenTerminal.exe`，并在隔离的设置和 PATH 环境中测试打包后的 EXE。复制程序时需保留整个 `BigScreenTerminal` 文件夹。

Windows 真正关机后的定时开机需要主板 BIOS/UEFI 的 RTC 功能或其他硬件唤醒方式，本程序不配置定时开机。
